# Sonneveld House · An index of objects

A static website that shows the living room and bedroom scans of Sonneveld House in the SuperSplat viewer, as an index of archival material. Each labelled object opens a dossier with:

- archive images,
- the life of the object (origin, making, the house, the archive),
- its materials and where they came from, with colonial sources flagged,
- open questions,
- references.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The page: title, room switch, dossier panel, index, image lightbox |
| `Sonneveld_Livingroom.sog`, `Bedroom.sog` | The scans |
| `build.py` | **Edit here.** All dossier texts, images, references, 3D label positions and cameras |
| `dossiers.json`, `settings-livingroom.json`, `settings-bedroom.json` | Generated by `python build.py`. Don't edit by hand |
| `viewer/` | SuperSplat viewer v1.37.0 (`@playcanvas/supersplat-viewer`, MIT licence) |

## Run locally

The page must be served over http:

```
python -m http.server 8000
```

Then open http://localhost:8000. Add `?room=bedroom` to open the bedroom directly.

## Editing dossiers

Each dossier in `build.py` has:

- a title (max 60 characters) and a summary (max 280);
- `life` stages;
- `materials`, where `colonial: True` adds the red flag;
- `questions` and `refs`;
- `images`, taken from the Nieuwe Instituut's Sonneveld House pages and credited with the archive's own captions;
- for objects in the scans, a 3D `position` and a `camera` to fly to. Coordinates are in metres, y up, floor at about y = -0.2.

Entries in `HOUSE` have no 3D position and appear only in the index.

Images are loaded from the archive's servers, not copied, so each one links back to its source page.

## Publishing

Upload the whole folder to any static host (GitHub Pages, Netlify, a TU Delft web space). The scans are 33 MB and 22 MB, within GitHub's 100 MB file limit.
